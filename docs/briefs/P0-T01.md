# P0-T01 Monorepo scaffold — brief

Owner: main (architect-direct). Depends: none. ADRs: 10, 11, 13, 19.

## Goal

The empty skeleton every later task lands in, plus the gate that guards it. No product code, no
placeholder UI beyond one screen that proves the toolchain runs.

## File manifest

Root
- `package.json` (private, scripts: `gate`, `gate:app`, `gate:rust`, `typecheck`, `lint`, `test`, `build`), `pnpm-workspace.yaml`
- `tsconfig.base.json` (strict + the extra strict flags), `tsconfig.json` (solution, project references)
- `.oxlintrc.json`, `vitest.config.ts`, `.editorconfig`, `.env.example`
- `LICENSE` (Apache-2.0 full text), `NOTICE`
- `.github/workflows/ci.yml`

Workspace members
- `apps/web/` — Vite + React 19 + TS strict, `src/main.tsx`, `src/App.tsx`, one smoke test
- `packages/protocol|core|providers|avatar|ml-web/` — `package.json`, `tsconfig.json` (composite),
  `src/index.ts` placeholder export, one test that proves the package builds and imports
- `companion/` — cargo workspace, `crates/server` binary `latentpresence-companion`, axum `/health`,
  a test that calls the router directly (no port bound)

Not in this task: `apps/desktop` (P0-T08), `site/` (P0-T03), `assets/` (Phase 2/7), `theme.css` (P0-T02b).

## Rules that apply

- No colour literals anywhere outside a `:root` block; P0-T02b brings the real tokens, so `apps/web`
  ships the minimum inline styling needed to see that it rendered, in a `:root`-driven stylesheet.
- No `any`. No `unwrap()`/`expect()` on I/O paths in Rust.
- `.gitattributes` already pins LF; do not add CRLF files.
- Gate order mirrors CI exactly: `tsc -b`, oxlint, vitest, vite build, `cargo fmt --check`,
  `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace`.

## Done when

1. `pnpm install && pnpm gate` succeeds from a clean clone on Windows.
2. `pnpm gate:app` and `pnpm gate:rust` each run half the gate.
3. CI workflow runs the same commands the README gives a contributor, on ubuntu and windows.
4. `tsc -b` type-checks every workspace member through project references, not a glob.
5. README's quick start is the commands that actually work.
