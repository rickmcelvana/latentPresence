## Verified surface — 2026-09-11, read from the installed `dist/index.d.ts` and the bundled provider docs

Use these names exactly. Do not infer them from the OpenAI-compatible provider, which differs.

| Fact | `@ai-sdk/anthropic@4.0.52` | `@ai-sdk/google@4.0.67` |
|---|---|---|
| Factory | `createAnthropic(options?: AnthropicProviderSettings): AnthropicProvider` | `createGoogle`, also exported as **`createGoogleGenerativeAI`**, `(options?: GoogleProviderSettings): GoogleProvider` |
| Settings type export | `AnthropicProviderSettings` | `GoogleProviderSettings` (alias `GoogleGenerativeAIProviderSettings`) |
| Settings fields used | `baseURL?`, `apiKey?` (sent as `x-api-key`), `headers?: Record<string, string>`, `fetch?: FetchFunction` | `baseURL?`, `apiKey?` (sent as `x-goog-api-key`), **`headers?: Record<string, string \| undefined>`**, `fetch?: FetchFunction` |
| Default base URL | `https://api.anthropic.com/v1` | `https://generativelanguage.googleapis.com/v1beta` |
| Model handle | provider is callable: `provider(modelId)` returns a `LanguageModelV4` | same: `provider(modelId)` returns a `LanguageModelV4` |
| Model id type | `AnthropicModelId` is a union **ending in `(string & {})`**, so any string compiles | `GoogleModelId`, same shape |
| Generic? | **No** — `createAnthropic` returns a plain `AnthropicProvider`, so no `ReturnType<...>` cast is needed (unlike `createOpenAICompatible`) | No — returns `GoogleProvider` |
| Prompt caching | documented (`providerOptions.anthropic.cacheControl`) so `promptCaching: true` | documented (implicit and explicit caching, `cachedContent`) so `promptCaching: true` |
| Context window | **not stated in the installed types or bundled docs** | **not stated in the installed types or bundled docs** |

`FetchFunction` is not exported by either package, so the `fetch` option is assigned through `NonNullable<XProviderSettings['fetch']>` exactly as `openai-compatible.ts` does. `HttpFetch` (from `./discovery`) is our structural fetch type and is what the config accepts.

## Spec

### Model discovery: a curated catalog, not a live call

Native providers have **no `/v1/models`-style discovery endpoint reachable from the browser**. `listModels()` returns a small curated `LlmModel[]` catalog and never makes a network call. It must still be `async` — `LLMProvider.listModels` returns a `Promise`.

`LlmModel` is `{ id, label, capabilities, embeddingOnly }`. **`contextLength` is a field *inside* `capabilities`, not a field on `LlmModel`** — see `packages/protocol/src/capabilities.ts`. Getting this wrong is the most likely way this task fails `tsc`.

The catalogs are written out in full in the reference code below. Two things about them:

- **The model ids are current as of 2026-09-11 and were checked against the installed `AnthropicModelId` / `GoogleModelId` unions.** Do not substitute ids you remember from elsewhere; `claude-sonnet-4-5`, `claude-opus-4-1` and the `gemini-2.5-*` family are previous generations and are deliberately not in the catalog.
- **`contextLength` is `200000` for `claude-haiku-4-5` and `1000000` for the other two Anthropic models** (Anthropic's published model table, cached 2026-06-24 — Rick confirms these against the live Models API in the manual verify). It is **`null` for every Google model**, because no context window is stated anywhere in the installed Google surface and SURFACE 11 / ADR-22 forbid presenting a guess as a fact. `null` there is the decision, not an omission — do not fill it in.

`capabilities` itself is non-null on every catalog entry: this is the enriched path, so ADR-22's nullable case never applies here.

`thinking: true` records that the *model* can produce a separate reasoning stream, which `mapStreamPart` already routes to `reasoning-delta`. Our `stream()` sets no `providerOptions`, so nothing is requested by default; the flag is a capability the picker shows, not a promise about this call.

### `stream()`

Identical body to `openai-compatible.ts`, given in full below: `streamText({ model, messages: toAiMessages(...), tools: toAiTools(...), abortSignal, temperature?, maxOutputTokens? })`, iterate `result.fullStream`, `mapStreamPart(part, this.now)`, skip `null`. Cancellation via the caller's `signal` aborts an `AbortController`, and the listener is removed in a `finally`.

### `packages/providers/src/llm/anthropic.ts`

```ts
import { streamText } from 'ai';
import {
  createAnthropic,
  type AnthropicProvider,
  type AnthropicProviderSettings,
} from '@ai-sdk/anthropic';
import type {
  CancellationSignal,
  LLMProvider,
  LlmModel,
  LlmRequest,
  LlmStreamChunk,
} from '@latentpresence/protocol';
import type { HttpFetch } from './discovery';
import { mapStreamPart, toAiMessages, toAiTools } from './mapping';

/** How a user configures the native Anthropic endpoint (P1-T03). `apiKey` is a BYO key
 * from the settings key store, never from this object's own rendering; `baseUrl` is only
 * for a proxy, since the provider already knows the real one. */
export interface AnthropicConfig {
  /** Stable provider id, stored in settings. */
  readonly id: string;
  readonly apiKey?: string;
  /** Overrides the default `https://api.anthropic.com/v1`, for proxies. */
  readonly baseUrl?: string;
  readonly headers?: Record<string, string>;
  /** Injected transport for tests; defaults to the global `fetch`. */
  readonly fetch?: HttpFetch;
}

/**
 * The models this provider offers. Native Anthropic has no browser-reachable listing
 * endpoint, so the catalog is curated rather than discovered — and because it is curated
 * it is the enriched path, with `capabilities` always non-null (ADR-22 covers the
 * opposite case, the un-enriched `/v1/models` list).
 */
export const anthropicCatalog: readonly LlmModel[] = [
  {
    id: 'claude-opus-5',
    label: 'claude-opus-5',
    capabilities: {
      streaming: true,
      toolCalls: true,
      structuredOutput: true,
      thinking: true,
      promptCaching: true,
      vision: true,
      contextLength: 1000000,
    },
    embeddingOnly: false,
  },
  {
    id: 'claude-sonnet-5',
    label: 'claude-sonnet-5',
    capabilities: {
      streaming: true,
      toolCalls: true,
      structuredOutput: true,
      thinking: true,
      promptCaching: true,
      vision: true,
      contextLength: 1000000,
    },
    embeddingOnly: false,
  },
  {
    id: 'claude-haiku-4-5',
    label: 'claude-haiku-4-5',
    capabilities: {
      streaming: true,
      toolCalls: true,
      structuredOutput: true,
      thinking: true,
      promptCaching: true,
      vision: true,
      contextLength: 200000,
    },
    embeddingOnly: false,
  },
];

/**
 * The native Anthropic LLM provider, built on the AI SDK (ADR-04). Same contract as
 * `OpenAICompatibleLLMProvider`: the AI SDK owns the wire format, this class owns the
 * bridge to the protocol's shapes. Prompt caching is the flag that earns the native
 * adapter its place — the OpenAI-compatible path cannot report it.
 */
export class AnthropicLLMProvider implements LLMProvider {
  readonly id: string;
  private readonly config: AnthropicConfig;
  private readonly now: () => string;

  constructor(config: AnthropicConfig, now: () => string = () => new Date().toISOString()) {
    this.id = config.id;
    this.config = config;
    this.now = now;
  }

  /** The curated catalog. No network call: there is nothing to discover. */
  async listModels(): Promise<LlmModel[]> {
    return [...anthropicCatalog];
  }

  /** Stream a chat completion as protocol chunks. Cancellation (barge-in) aborts the
   * underlying fetch by wiring the caller's `signal` to an `AbortController`. */
  async *stream(
    request: LlmRequest,
    options?: { signal?: CancellationSignal },
  ): AsyncIterable<LlmStreamChunk> {
    const model = this.buildProvider()(request.modelId);

    const controller = new AbortController();
    const onAbort = (): void => controller.abort();
    options?.signal?.addEventListener('abort', onAbort);
    try {
      const result = streamText({
        model,
        messages: toAiMessages(request.messages),
        tools: toAiTools(request.tools),
        abortSignal: controller.signal,
        ...(request.temperature !== null ? { temperature: request.temperature } : {}),
        ...(request.maxOutputTokens !== null ? { maxOutputTokens: request.maxOutputTokens } : {}),
      });
      for await (const part of result.fullStream) {
        const chunk = mapStreamPart(part, this.now);
        if (chunk !== null) yield chunk;
      }
    } finally {
      options?.signal?.removeEventListener('abort', onAbort);
    }
  }

  private buildProvider(): AnthropicProvider {
    const settings: AnthropicProviderSettings = {};
    if (this.config.baseUrl !== undefined) settings.baseURL = this.config.baseUrl;
    if (this.config.apiKey !== undefined) settings.apiKey = this.config.apiKey;
    if (this.config.headers !== undefined) settings.headers = this.config.headers;
    if (this.config.fetch !== undefined) {
      settings.fetch = this.config.fetch as NonNullable<AnthropicProviderSettings['fetch']>;
    }
    return createAnthropic(settings);
  }
}
```

## Tests, each with the invariant it protects

Streaming needs a real key (producer-owned manual test), so the unit tests cover the deterministic surface only. **No test may make a network call.** Style: `import { describe, expect, it } from 'vitest'` and one `describe` per exported class, as in `fake.test.ts`.

`anthropic.test.ts`:

- `listModels returns the curated catalog with capabilities on every entry` — would fail if a native adapter hid its capability flags or returned `capabilities: null`; guards that the picker can present these models at all. Assert `embeddingOnly === false` on every entry in the same test.
- `reports promptCaching true on every catalog model` — would fail if the task's headline flag were missing or misreported.
- `catalog context lengths are the documented ones` — asserts `200000` for `claude-haiku-4-5` and `1000000` for the other two, read from inside `capabilities`; would fail if a later edit moved or invented the number.
- `listModels makes no network call` — construct with `fetch` set to a spy that throws, `await listModels()`, assert the spy was never called; would fail if someone "improved" the catalog into a live listing.
- `AnthropicLLMProvider satisfies LLMProvider (id + listModels + stream)` — assign an instance to an `LLMProvider`-typed local and assert `provider.id`; would fail if a provider stopped satisfying the protocol contract.

`google.test.ts`:

- `listModels returns the curated catalog, capabilities non-null on every entry` — would fail if the native path ever returned `capabilities: null`; it is the enriched path, unlike `/v1/models`.
- `every catalog model reports contextLength null` — would fail if someone filled in a guessed context window; this is the SURFACE 11 invariant, and it is deliberate.
- `reports promptCaching and thinking true on every catalog model`.
- `listModels makes no network call` — as above.
- `GoogleLLMProvider satisfies LLMProvider (id + listModels + stream)`.

Do **not** write a test that calls `stream()` — it would reach the network. Stream shape is already covered by `mapping.test.ts` and `fake.test.ts`.

**Lesson for the next brief that touches a nullable protocol field:** when the reference code annotates a const with a protocol type, say in the Tests section how the test is expected to narrow it. Aider had no way to infer that from a prose invariant, and it is the only thing that went wrong here.
