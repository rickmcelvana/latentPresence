## 1. Sources under an answer — `apps/web/src/transcript/TranscriptPanel.tsx`

- New optional prop `sources?: (ref: string) => CitationSource | undefined`, where
  `CitationSource` is exported from the panel's module: `{ title: string; locator: string | null;
  source: string; text: string }`. (`ChatPage` will build it from the hits she was given.)
- An assistant line with `citations.length > 0` renders, under its text, a list headed
  "Sources" (a small heading, not a live region of its own): one item per ref, numbered from 1,
  showing `title` and, when there is one, `, ${locator}` — e.g. "1. Boiler manual, p. 12".
  Each item is a `<details>`: its `<summary>` is that line; opened, it shows the chunk `text` (as
  a quote) and the `source` path in small monospace. A ref `sources` does not know (or no
  `sources` prop at all) renders as "N. A source she was not given" in the muted/warn style, with
  no details — that is a citation she made up.
- A streaming line shows its sources as they arrive; an interrupted one keeps them.
- `transcriptToText` (core) is not yours; leave copying as it is.

## 2. The switch — `apps/web/src/settings/settings.ts` and `DocumentsSection.tsx`

- Settings document: `documents: z.object({ search: z.boolean() }).default({ search: false })`
  on `SettingsSchema`, with `DEFAULT_SETTINGS.documents = { search: false }` and a doc comment
  (P5-T04, ADR-45: off by default, no unasked request to `127.0.0.1`). Update the settings tests'
  literals as `companion: false` was handled in P5-T02.
- `DocumentsSection` gets `search: boolean` and `onSearchChange: (search: boolean) => void`

  section's switches (`role="switch"`), label "Let her search these documents". `SettingsPanel`
  passes `settings.documents.search` and an updater, as it does for the others.
