latentPresence 1.0, the first stable release. If you have 0.2 installed, Check for updates brings you here, and your conversations, memory and settings stay.

New since 0.2.1:
- Theo has his own body, a VRoid Studio model. Like every download, it asks first (15.4 MB).
- Captions, and keys for the call: M to mute, C for captions, T to type, Esc to close the side panel. The page respects reduced motion.
- Every call button is reachable at any window size. Before, a window narrower than about 1440 pixels cut off Start voice and Settings.
- Every model and body download is pinned to a fixed version and checked against its SHA-256 before it is used or kept. Her voice runtime now comes with the app, not from a CDN.
- A privacy page in the app (/privacy) says what goes where, and lists every model it can download with its licence.
- Security: the companion answers only requests addressed to it, and the page may load scripts only from the app itself.
- Leaving from the Small window no longer makes the next launch open small.
- A user guide at https://latentpresence.com/docs/

Known:
- The installer is not code-signed yet: when Windows SmartScreen asks, choose More info, then Run anyway.
- Talking out loud needs a GPU with WebGPU, and the first call downloads about 480 MB of voice models.
- macOS and Linux have no app yet: use https://app.latentpresence.com in Chrome or Edge.
