# R-8 · Hear the character remember you — run 2026-09-22

Run by Rick on the Windows box at `/dev/voice` with **Model: live model from /settings**
and a SteelSeries Sonar microphone; instructions as run are `docs/TASKS.md` R-8 at 0a0cb1e
(now Done, D-22). Rick's verdict: **"works as intended."**

**Two legs, same script:** `glm-5.2:cloud` (Ollama cloud) first, then **`gemma4:12b-it-qat`

This is the first time the **whole spoken pipeline has run against a real language model** —
every earlier harness run used the scripted answer, which ignores its request entirely.

## By ear (Rick)

- **Works as intended.** Recall across turns, and a cut-off answer repeated back as only
  what was heard.

## Reading

- **The spoken path remembers, and it is the history doing it.** "My wife's name is Jamie."
  → "What did I say, my wife's name is?" → **"Jamie. You said your wife's name is Jamie."**
  Before P1-T12b that second turn was a standalone request and could only have guessed.
- **The heard-not-meant rule held on a real barge-in, and the evidence is better than the
  assertion.** Rick cut the answer at `…Pakistan, Nigeria,` — the log's `barge-in committed;
  heard:` line ends on exactly those words. Asked "What did you say?", the character replied
  **"India, China, the US, Indonesia, Pakistan, and Nigeria. That's the top six."**
  It counted the six it had actually said. The seventh country it was in the middle of
  generating is not in the answer, because it was never in the history.
- **ADR-25's retraction happened in the wild and left nothing behind** (row 3). Smart Turn
  scored 0.96, the turn ended, and speech resumed 320 ms later — inside the hangover. The
  turn is `retracted`, has no transcript line, and **contributed nothing to the next
  request**. P1-T12b's unit test for this now has a real occurrence behind it, and it is the
  first retraction seen with a person since R-2 saw none in four turns (D-17).
- **The model dominates, and local is the slower one.** Speech end → first audio, cloud:
  4189, 1805, 4297, 6091 ms. Local `gemma4:12b-it-qat`: **17761** (cold), 4800, 9193,
  7544 ms. First-sentence synthesis is small and steady in both (299–818 cloud, 355–536
  local), and turn ends land 218–275 ms after speech in both, so **our own pipeline is
  unchanged and within ADR-20's 500 ms; everything above it is the model**. Roughly:
  4.4 s of model time on the local turn 2 against 1.5 s on the cloud one.
- **This confirms ADR-20 rather than challenging it.** The ADR budgets "under 500 ms …
  **excluding the model call**" and says end-to-end is "reported, not promised … a local
  model's first token can exceed the whole remaining allowance". That is precisely what
  happened. **The intuition it corrects is that local means fast**: on this box a 12B local
  model is two to four times slower to first audio than a cloud endpoint, which matches
  `live:persona`, where the same model took 9–41 s for a full reply.
- **A `hangover 0.69` and a `hangover 0.56`** (rows 2 and 5) — Smart Turn scored a complete
  question below the 0.7 threshold and the hangover closed it, as R-2 saw three times of
  four. Still P1-T14's to look at.
